# 三位一体技术分析策略

## 概述

基于"三位一体操作策略"的股票技术分析系统，通过均线系统(MA55/MA233)、结构拓扑(A五段式/B双平台式/C单平台式/D三段式)、时空振荡器(MACD六种状态)三个维度解构市场，支持多周期级别嵌套分析。

## 使用级别

三位一体分析实际使用 **5个级别**（不包含5分钟）：

| 级别 | 代码 | 描述 | 用途 |
|------|------|------|------|
| 周线 | `w` | 大级别趋势判断 | 判断大方向 |
| 日线 | `d` | 主要操作级别 | 结构分析核心 |
| 60分钟 | `60` | 日内防守级别 | 中线支撑压力 |
| 30分钟 | `30` | 短线交易级别 | 买卖点定位 |
| 15分钟 | `15` | 微观买卖点 | 精确入场时机 |

**重要**：5分钟级别不参与三位一体分析，同步失败也不应显示。

## 一、MACD时空状态（六种状态循环）

### 1.1 状态定义

| 状态 | DIF位置 | DEA位置 | 金叉/死叉 | 特征描述 |
|------|---------|---------|-----------|----------|
| **极强** | 零轴上 | 零轴下 | - | 上涨动能最充沛，DIF首次上穿零轴 |
| **强** | 零轴上 | 零轴上 | 金叉 | 持有阶段，DEA已确认上穿 |
| **中偏强** | 零轴下 | 零轴下 | 金叉 | 转强阶段，低位金叉后等待上穿 |
| **中偏弱** | 零轴上 | 零轴上 | 死叉 | 转弱阶段，高位死叉后等待下穿 |
| **弱** | 零轴下 | 零轴下 | 死叉 | 空头主导，等待低位金叉 |
| **极弱** | 零轴下 | 零轴上 | - | 下跌动能最充沛，DIF下穿零轴 |

### 1.2 状态黑话与应对法则

| 状态 | 状态黑话 | 核心应对法则 |
|------|----------|-------------|
| **极强** | 无视顶背离 | 大级别极强会用时间换空间消解小级别背离。**核心买点：逢股价回抽MA55线无脑买入** |
| **强** | 波段操作区 | B类上涨结构：忽略小级别波动，在b1/b3/b5/b7低吸。D类下跌结构：如在d1卖出，必须在d3接回，最终在d4确认加仓 |
| **中偏强** | 中枢试仓区 | 对应C类单平台结构，允许在中枢底部试仓（轻仓布局），但必须叠加严格的止损逻辑 |
| **中偏弱** | 防御性试仓 | 与中偏强同理，对应C类中枢结构，仅限底部严格止损试仓 |
| **弱** | 高抛减仓区 | B类下跌结构：在反弹的b1/b3/b5/b7位置坚决卖出。D类上涨结构：买入需极度谨慎，在d3节点必须执行卖出清仓 |
| **极弱** | 无视底背离 | 空头动能最盛，小心骗线。**绝对禁止抄底，逢股价反弹触及MA55线即为绝佳卖空/止损机会** |

### 1.3 背离四大特征（重要）

**背离定义**：股价创新高/新低，但趋势动能（MACD红绿柱面积或黄白线）出现衰退的矛盾现象。

**四大特征**（防止"背了又背"陷阱）：

1. **极强/极弱状态豁免**：
   - 极强状态下，所有小级别的**顶部背离全部失效**
   - 极弱状态下，所有小级别的**底部背离全部失效**

2. **新高/新低前置条件**：
   - 没有创出价格的新高或新低，绝对禁止研判背离

3. **零轴牵引确认**：
   - 背离引发的调整是否到位，重要标志是MACD的快慢线必须至少被拉回至零轴附近

4. **背离的级别传导**：
   - 大级别的拐点必然由次级别的顶底背离传导而来

## 二、结构拓扑（四种基本结构）

### 2.1 结构类型定义

| 结构 | 笔数 | 拐点 | 操作要点 |
|------|------|------|----------|
| **A五段式** | 5笔 | 6拐点(a1-a6) | 第三浪是主升/跌浪，趋势最强烈 |
| **B双平台式** | 9笔 | 10拐点(b1-b10) | 双平台整理，奇数点(b1,b3,b5,b7,b9)是操作点 |
| **C单平台式** | 5笔 | 6拐点(c1-c6) | 单平台整理，中枢上下沿是操作边界 |
| **D三段式** | 3笔 | 4拐点(d1-d4) | 最小完整结构，d1、d4是关键操作点 |

### 2.2 结构黑话释义

**A类结构黑话**：
- **A1**：指代 a1→a2（第一推动浪），趋势启动的第一波攻击
- **A2**：指代 a3→a4（主升浪），利润最丰厚的波段。"捕捉A2段"意指在a3节点建仓
- **A3**：指代 a5→a6（末浪），常伴随MACD结构性背离

**B类结构黑话**：
- **B1**：代表第一平台筹码交换期（b1-b4），奇数点(b1,b3)是下轨边界
- **B2**：代表平台间跃迁连接段（b5-b6），突破第一平台后的延伸
- **B3**：代表第二平台高位/低位派发与洗盘期（b7-b10）
- **重要**：双平台在价格区间上不得有任何重叠，否则不是标准B类结构

**C类结构黑话**：
- **C1/C2/C3**：代表中枢内部的三个主要震荡次级别线段
- 操作指令始终为"在中枢底部（如c1、c3、c5连线的下轨）可试仓，但必须严格止损"

**D类结构核心概念**：
- **d3不稳定点**：反向修正的终点
  - 在"强"状态下跌中，d3是**卖出不稳定点**（后续可能继续下跌）
  - 在"弱"状态上涨中，d3是**买入不稳定点**（后续可能继续上涨）
- **d4衰竭点**：第二段攻击/杀跌的终点
  - 在下跌结构中，d4是**空头衰竭买入机会**
  - 在上涨结构中，d4是**多头衰竭卖出机会**

### 2.3 结构必完美定理

**定理内容**：判断更大级别空间调整是否结束的唯一标准，是在宏观一笔下跌中，必须嵌套包含一个完整的次级别D类结构（d1→d2→d3→d4）。

**应用规则**：
- 若无完整的三段式结构，说明空间调整不充分，不宜盲目抄底
- 只有当次级别出现完整D类结构后，大级别调整才算充分

## 三、时空要素和结构要素应用表

核心逻辑：**大级别（日线）时空状态 + 小级别（30分钟/15分钟）结构 = 操作建议**

| 时空状态 | 下跌结构 | 下跌操作要点 | 上涨结构 | 上涨操作要点 |
|----------|----------|--------------|----------|--------------|
| **极强** | 无 | 小心被洗走 | A, B | 忽略顶部背离，逢回抽MA55线买入机会 |
| **强** | D | 卖出谨慎，d1卖出后d2接回，d3不稳定，d4买入 | B | 忽略小级别波动，b1/b3/b5/b7波段买入 |
| **中偏强** | C | 中枢底部可试仓，严格止损 | C | 中枢底部可试仓，严格止损 |
| **中偏弱** | C | 中枢底部可试仓，严格止损 | C | 中枢底部可试仓，严格止损 |
| **弱** | B | 忽略小级别波动，b1/b3/b5/b7波段卖出 | D | 买入谨慎，d3买入不稳定，d4卖出 |
| **极弱** | A, B | 忽略底部背离，逢回抽MA55线卖出 | 无 | 小心被骗线 |

## 四、均线系统物理性质

### 4.1 四大核心性质

| 性质 | 描述 | 应用 |
|------|------|------|
| **支撑与压制** | 均线的根本任务是维护趋势现状。任何未伴随结构破坏的触线，均应优先判定为支撑或压制有效 | 判断趋势是否被破坏 |
| **牵引性** | 当股价过度偏离MA55/MA233时，均线产生回归引力。首次突破或跌破MA55/MA233，必定伴随回抽确认动作 | 预判回抽确认 |
| **共振性** | 不同级别均线在同一价格区间重合时，支撑或压制效力指数级放大 | 寻找关键价位 |
| **同一性** | 均线系统在不同标的、不同级别的有效性一致 | 跨标的验证 |

### 4.2 突破/跌破形态识别

**突破形态（向上穿越均线）**：

| 形态 | 特征 | 有效性 |
|------|------|--------|
| **假突破** | 未到均线即反弹，或突破后迅速被拉回 | 无效，诱多 |
| **有效突破** | 实体幅度大，超过前序K线平均振幅1.5倍 | 有效，看涨 |
| **慢速突破** | 以盘整形态缓慢穿越均线 | 最不可靠，易反向抽回 |
| **回抽突破** | 突破后回抽确认 | 最确定，看涨 |
| **反向突破** | 压制反弹后反向突破 | 爆发力最强，看涨 |

**跌破形态（向下穿越均线）**：

| 形态 | 特征 | 有效性 |
|------|------|--------|
| **假跌破** | 未到均线即回落，或跌破后迅速被拉回 | 无效，诱空 |
| **有效跌破** | 实体幅度大，超过前序K线平均振幅1.5倍 | 有效，看跌 |
| **慢速跌破** | 以盘整形态缓慢穿越均线 | 最不可靠，易反向抽回 |
| **回抽跌破** | 跌破后回抽确认 | 最确定，看跌 |
| **反向跌破** | 支撑反弹后反向跌破 | 杀伤力最强，看跌 |

## 五、级别嵌套分析（三维度）

### 5.1 三维度框架

| 维度 | 大级别 | 小级别 | 用途 |
|------|--------|--------|------|
| **维度一** | 周线 | 日线 | 判断大级别趋势方向 |
| **维度二** | 日线 | 30分钟 | 寻找具体买卖点 |
| **维度三** | 60分钟 | 15分钟 | 日内或短线操作 |

### 5.2 分析原则

**分析自上而下，交易自下而上**

1. 先看大级别趋势方向
2. 再到小级别寻找结构
3. 在更小级别定位买卖点

## 六、时空双重确认（判断宏观调整结束）

### 6.1 空间确认（寻找D结构）

1. 确认日线级别的起调点（如头肩顶右肩高点）
2. 审查周线级别下跌中，日线是否包含完整的D结构
3. 无完整日线D结构 = 空间未跌透

### 6.2 时间确认（三周时间偏差法则）

1. 时间调整充分依据是对称性
2. 比较周线当前下跌时间与前一段下跌时间
3. **严格约束：时间偏差绝对不能超过3周**
4. **必须使用周线级别K线数计算，严禁用日线（含节假日干扰）**

### 6.3 时空共振

- 当空间确认+时间确认同时满足
- 未来上涨极具爆发力，不应减仓
- 收紧至60分钟MA55监控，突破即全面进攻信号

## 七、仓位管理铁律

### 7.1 起手与加仓法则（正金字塔模型）

**起手仓位**：
- 在C类中枢底部试仓，或在突破回踩时发出"起手仓位"指令
- 起手仓位应轻仓试探，目的是建立"入场感"

**加仓法则**：
- 当价格放量完成有效突破进入"极强状态"时，产生"浮盈加仓"指令
- **正金字塔递减法则**：每一次追加的筹码必须少于前一次
  - 第一次加仓：≤ 起手仓位的100%
  - 第二次加仓：≤ 第一次加仓的50%
  - 第三次加仓：≤ 第二次加仓的50%

### 7.2 固定止损铁律

**核心原则**：依据什么级别建仓，就必须依据什么级别止损

**禁止行为**：
- 若基于日线级别的C类中枢发出起手买入指令
- 一旦日线级别有效跌破中枢下沿
- **必须立即执行平仓指令**
- **严禁在日线破位后，擅自将分析周期放大至周线或月线寻找新的支撑位进行"自我安慰式"的死扛**

### 7.3 右侧补仓铁律

**禁止左侧补仓（接飞刀）**：严禁在下跌的"半山腰"进行左侧补仓

**右侧补仓条件**（必须同时满足）：
1. 价格完成V型反转
2. 有效突破MA55
3. 或出现确认的日线底分型（右侧确立）

**补仓资金管理**：
- 15分钟级别反弹：最多补总仓位的1/4
- 30分钟级别反弹：最多补总仓位的1/3
- 日线级别反弹：最多补总仓位的1/2

### 7.4 倒金字塔跟踪止盈

**触发条件**：
- 结构运行至A类结构末端（a5-a6段）或B类结构b9节点
- 伴随小级别（15/30分钟）顶背离

**止盈策略**：
- 高位抛出较大比例的获利筹码（如首抛50%）
- 随着价格回落逐渐减少抛售量（如二抛30%、三抛15%）
- 保留底仓以应对可能的"时间换空间"横盘

## 十、核心代码实现要点

### 10.1 MACD状态判定逻辑

文件：`scripts/stock_analyzer.py` - `determine_macd_status()` 方法

**关键事件追踪**：
- 低位金叉：DIF上穿DEA，两者都在零轴下方
- 高位死叉：DIF下穿DEA，两者都在零轴上方
- DIF上穿零轴
- DIF下穿零轴
- DEA上穿零轴
- DEA下穿零轴

### 10.2 结构识别算法

文件：`scripts/stock_analyzer.py`

**有效区间确定算法**（`_find_valid_range` 方法）：

**左边界（起点/原点）**：
- 判定条件：MACD 状态切换处（金叉/死叉，或 DIF 穿越零轴）
- 价格特征：该时期内的绝对最高价或绝对最低价

**右边界（终点）**：
- 策略：强制分析到最后一天，确保完整呈现聚类形态
- 破位记录：检测并记录第一次有效跌破/突破 MA55 的位置，用于重点提醒
- 箱体聚类：由后续的聚类算法自动处理破位后的走势，识别为"延伸 C 类"或新的中枢

**修改历史**：
- 原有逻辑问题：当价格跌破 MA55 后立即终止，导致后续走势被丢弃
- 优化方案：放开右边界，强制分析到最后一天，让箱体聚类算法自动处理

**箱体聚类合并算法**：
- 将机械的多笔结构聚类成宏观组件（平台/连接段）
- 重叠率阈值：55%
- 组件类型：Platform（≥3笔的平台）、Directional（<3笔的单边）

**结构分类规则**：
- 单组件：Platform → C类，Directional → D类
- 双组件：双平台不重叠 → B类
- 三组件：平台+连接段+平台（不重叠）→ B类
